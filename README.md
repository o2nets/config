## ویتوری چیست؟

**V2Ray** (ویتوری) یک پروژه متن‌باز برای ساخت شبکه‌های امن و دور زدن محدودیت‌های اینترنتی است. این ابزار از پروتکل‌های مختلفی مانند **VMess**، **VLESS**، **Trojan** و **Shadowsocks** پشتیبانی می‌کند و به دلیل انعطاف‌پذیری بالا، یکی از محبوب‌ترین راه‌حل‌های فیلترشکن در ایران محسوب می‌شود.

برخلاف VPNهای سنتی، کانفیگ‌های V2Ray روی **تمام اپراتورها** از جمله همراه اول، ایرانسل، مخابرات، رایتل و مبین‌نت قابل استفاده هستند و روی **اندروید، آیفون، ویندوز، مک و لینوکس** کار می‌کنند.

## چه چیزی با خرید کانفیگ دریافت می‌کنید؟

4. **آپدیت خودکار** — سرورها به‌روزرسانی می‌شوند و شما نیازی به تغییر دستی ندارید.
5. **تست رایگان** — بسیاری از سرویس‌دهنده‌ها قبل از خرید، کانفیگ تست ارائه می‌دهند.
